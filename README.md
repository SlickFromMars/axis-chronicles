# Axis Chronicles

A web-based campaign journal for tabletop RPG campaigns, inspired by the presentation and organization of games like *Baldur's Gate 3*.

**Live Site: [Axis Chronicles](https://slickfrommars.github.io/axis-chronicles)**

Axis Chronicles provides a centralized place to keep track of:

* Campaign journals and sessions
* Quests and objectives
* Player characters and companions
* Interactive maps and locations
* Campaign music and soundtracks
* Session calendars

The site is designed to support **multiple campaigns** while keeping each campaign's content, appearance, and data separate.

## Add Your Own Campaign

Want to use Axis Chronicles for your own tabletop RPG campaign? You can add a campaign by editing JSON files—no HTML, CSS, or JavaScript knowledge required for ordinary campaign content.

**[Read the Creating a Campaign Wiki](https://github.com/SlickFromMars/axis-chronicles/wiki/Creating-a-Campaign)** for a step-by-step guide to:

* Creating and registering a campaign
* Configuring its name, theme, and tabs
* Adding characters, quests, locations, sessions, and music
* Setting up character portraits and map artwork
* Checking your JSON and troubleshooting common issues
