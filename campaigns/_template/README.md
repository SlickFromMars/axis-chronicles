# Campaign Template

Copy this entire `_template` folder into a new folder under `campaigns/` and rename that folder to match the campaign ID (lowercase words separated by hyphens). Then update `campaign.json` and `manifest.json` to use the same ID/name. Register the new campaign in `campaigns/index.json`. Do **not** add `_template` itself to the campaign registry.

## Included files

- `campaign.json`: all currently supported campaign configuration fields, including tabs, theme colors, file paths, text labels, quest categories, party teams, character categories, and map settings.
- `manifest.json`: installable-app metadata. Keep its name, description, start URL, scope, colors, and icon paths aligned with the campaign.
- `data/characters.json`: sample player character and NPC, showing both `team` and `location` usage across entries.
- `data/quests.json`: sample main and side quests, including objectives, character/location references, and developments.
- `data/locations.json`: sample region and settlement with map coordinates and a region reference. Coordinates are percentages from 0 to 100.
- `data/sessions.json`: sample scheduled session. Replace or remove it before publishing.
- `data/music.json`: sample music page and playlist sections. Replace the placeholder playlist URLs.
- `assets/characters/portrait-manifest.json`: maps character IDs to portrait filenames. Add matching image files in this folder, or remove sample entries until portraits exist.

## Important

The sample entries are intentionally illustrative. Replace or delete them before publishing. Every `id` should be unique within its data file. References in quest `characters` and `locations`, and location `region`, must match real IDs. The `team` values should match an ID in `party.teams`. Add the map image at `assets/map/map.webp` and branding images at the paths listed in `campaign.json` if you want to use those features. Calendar `.ics` files are generated by the repository preparation script; don't hand-edit a generated calendar.
